## Project Overview

Ce projet vise à réaliser une analyse exploratoire des données (EDA) sur un dataset de clients bancaires afin de comprendre la structure des données et préparer l’identification de profils clients, notamment ceux ayant accepté un prêt personnel.  
L’analyse s’inscrit dans une démarche data-driven orientée aide à la décision et ciblage client.

---

## Dataset Description

Le dataset regroupe des informations clients de Thera Bank couvrant :
- des données démographiques (âge, expérience, situation familiale, niveau d’éducation)
- des indicateurs financiers (revenu, dépenses par carte de crédit, crédit immobilier)
- l’utilisation de produits et services bancaires
- une variable cible indiquant l’acceptation d’un prêt personnel

Ces données permettent d’analyser le comportement client et le potentiel de souscription aux produits bancaires.

---

## EDA – Data Quality Check

Une première phase d’analyse exploratoire a été réalisée afin de vérifier l’intégrité du jeu de données.

- aucune valeur manquante détectée
- aucun doublon identifié

Le dataset est propre et directement exploitable pour l’analyse univariée et la visualisation des KPI.

---

## Tools & Technologies

- Python (pandas, numpy) pour l’exploration et la validation des données
- Power BI pour la visualisation des indicateurs et l’analyse descriptive
- Excel comme source de données

L’ensemble des outils est utilisé dans une logique d’analyse métier orientée compréhension client et prise de décision.
